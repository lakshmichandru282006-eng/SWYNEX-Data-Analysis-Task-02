# SWYNEX Internship – Task 2: Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a medical appointment dataset to identify trends, patterns, relationships, and anomalies that influence patient appointment attendance.

The analysis was performed using Python in Google Colab, with the aim of extracting meaningful insights through data cleaning, statistical analysis, and data visualization.

## Objectives

- Understand the structure and characteristics of the dataset.
- Perform statistical analysis on numerical and categorical variables.
- Explore patient demographics and appointment attendance.
- Identify trends and patterns affecting appointment no-shows.
- Analyze relationships between different variables.
- Detect anomalies and outliers in the dataset.
- Create visualizations to communicate findings effectively.

## Dataset Description

The dataset contains medical appointment records with information about patients, scheduled appointments, medical conditions, SMS reminders, and attendance status.

**Dataset size:** 110,526 records  
**Number of columns:** 14

Key attributes include:

- `PatientId` – Patient identification number.
- `AppointmentID` – Appointment identification number.
- `Gender` – Patient gender.
- `ScheduledDay` – Date the appointment was scheduled.
- `AppointmentDay` – Date of the actual appointment.
- `Age` – Patient age.
- `Neighbourhood` – Location of the hospital.
- `Scholarship` – Indicates participation in the welfare program.
- `Hipertension` – Indicates hypertension status.
- `Diabetes` – Indicates diabetes status.
- `Alcoholism` – Indicates alcoholism status.
- `Handcap` – Indicates handicap status.
- `SMS_received` – Indicates whether an SMS reminder was received.
- `No-show` – Indicates whether the patient missed the appointment.
